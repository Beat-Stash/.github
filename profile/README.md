# BeatStash

BeatStash builds software that keeps video in time with music.

## What we work on

- **Music analysis**: tempo, beat and section detection that finds
  the moments worth cutting on.
- **Media pipeline**: ingest, transcoding and delivery of video and
  audio through a CDN.
- **Playback**: a responsive web player for desktop, tablet and phone.
- **Platform**: accounts, subscriptions and the services behind them.

## How we build

- Python services on PostgreSQL, with a TypeScript and React front end.
- Containerised services on a managed cloud platform.
- Every change goes through review and automated tests before it ships.

Our repositories are private.
